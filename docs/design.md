# 设计与模块

中文 | [English](design.en.md)

## 目标

XIAO ESP32-S3 Sense 本地采集、识别和稳定化，经 ESP-NOW 输出离散手势事件。日常运行不依赖 PC 推理或互联网；先用接收测试工具独立验收。

数据路径：摄像头 → ROI/预处理 → 静态分类 → 稳定与释放状态机 → 事件输出

| 模块 | 责任 |
| --- | --- |
| capture | 帧获取与生命周期；记录分辨率、格式和失败原因 |
| inference | 预处理、模型调用、类别和置信度；记录模型版本 |
| stabilizer | DISABLED / ARMED / WAIT_RELEASE；持续姿态只触发一次 |
| transport | 版本、来源、序列号、确认和超时；发送不等于动作执行 |

## 接口初稿

候选语义字段：protocol_version、source_id、boot_id、sequence、gesture、confidence、stable。线上采用固定长度、明确字节序的版本化消息；编码和确认策略在 P03 冻结。发送端时间不用于跨设备直接相减。

此约定尚无已验证实现。冻结时补充样例、边界条件和版本迁移说明。

## 范围

首版只识别静态手势并输出事件；连续空中鼠标、动态轨迹手势和应用端动作执行不在本库范围。
