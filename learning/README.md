# 项目驱动学习路径

每阶段按“问题 → 原理 → 最小实验 → 观察 → 解释与局限”记录。

## P01：静态图片推理

学习任务：锁定 SDK 与模型依赖，独立构建；保存输入图片来源、真实输出、耗时和内存。

笔记需解释本阶段输入、输出、失败条件及为何采用当前方法。

## P02：实时手势

学习任务：接摄像头，测试手势、无人和自然动作；输出混淆矩阵、每小时误触次数和触发延迟。

笔记需解释本阶段输入、输出、失败条件及为何采用当前方法。

## P03：稳定事件

学习任务：持续姿态、离开再进入、重复包和断连测试；一次有效姿态只产生一次动作意图。

笔记需解释本阶段输入、输出、失败条件及为何采用当前方法。

## P04：桌面联调

学习任务：接入 Keyboard_as_PC-Hub；禁用状态不执行，失联释放，断网完成基础操作。

笔记需解释本阶段输入、输出、失败条件及为何采用当前方法。

## P05：模型改进

学习任务：分开训练与测试场景，对比光照、距离和背景；报告精度、延迟和资源权衡。

笔记需解释本阶段输入、输出、失败条件及为何采用当前方法。

资料按当前任务补充，不先堆积整套课程。
