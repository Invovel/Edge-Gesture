# 项目驱动学习路径

中文 | [English](README.en.md)

每阶段记录“问题 → 原理 → 最小实验 → 观察 → 解释与局限”。

## P01：静态图片推理

锁定 SDK 与模型依赖，独立构建；保存输入图片来源、真实输出、耗时和内存。

解释输入、输出、失败条件和设计选择。

## P02：实时手势

接摄像头，测试手势、无人和自然动作；输出混淆矩阵、每小时误触次数和触发延迟。

解释输入、输出、失败条件和设计选择。

## P03：稳定事件

持续姿态、离开再进入、重复包和断连测试；一次有效姿态只产生一次动作意图。

解释输入、输出、失败条件和设计选择。

## P04：事件接收验收

使用独立接收测试工具核对事件；禁用状态不发送操作事件，断连不补发过期操作，断网仍可识别与传输。

解释输入、输出、失败条件和设计选择。

## P05：模型改进

分开训练与测试场景，对比光照、距离和背景；报告精度、延迟和资源权衡。

解释输入、输出、失败条件和设计选择。

按当前任务补资料，不预先堆积课程。
